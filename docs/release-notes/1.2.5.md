# Mindwtr 1.2.5

## Highlights

- Protect File Sync, WebDAV, and Dropbox with a passphrase. Mindwtr encrypts sync documents, recovery copies, and attachments before they leave the device, and first-sync setup keeps plaintext out of the remote location.
- Organize Someday/Maybe with named sections that sync across devices, process Inbox items with the same quick-add language used during capture, and see each task’s project section in lists.
- Plan with a clearer Focus view: Review Due sits above Next Actions, Upcoming previews the next seven days, later-today tasks stay in Today, and mobile can hide row details.
- Repeat tasks on several days of a month or its true last day, see progress through count-limited series, and use more forgiving localized date entry.
- Capture from the iPhone Lock Screen or Control Center, view Today in the native macOS widget, and use safer attachment downloads on every supported sync backend.
- Type `/reference` and `/priority:` during quick add, export a filtered desktop list to CSV, sort tasks and projects by time estimate, and convert tasks into project sections or references.
- Large libraries spend less time sorting, copying, merging, serializing alarms, and refreshing unchanged SQLite data. Sync and attachment work now use stricter size, identity, timeout, and cancellation bounds.

## Capture & Inbox Processing

- Quick add parses natural-language dates in the active app language, respects numeric date format, and removes date-introducing words with locale-aware rules.
- `/priority:low`, `/priority:medium`, `/priority:high`, and `/priority:urgent` set priority during capture; `/reference` files information as Reference.
- Smart-quote substitutions work around quoted quick-add tokens, and context or tag tokens open only at a word boundary.
- Desktop and mobile Inbox Processing use the same quick-add syntax as capture. Guided and Quick modes preserve decisions across retries and clarify scheduling, project, and Incubate controls.
- Creating a project during Inbox Processing uses one Project Name field instead of asking for the same name twice.
- Mobile system capture routes through the stable capture modal, and inline checklist creation keeps focus on the new row without jumping the form.

## Tasks, Projects & Organization

- Someday/Maybe supports named, ordered sections across desktop and mobile. Sections can be created during assignment or managed in Settings, and unknown assignments survive older clients and section catalogue changes.
- Creating the first Someday section enables section grouping; later grouping choices remain under the user’s control.
- Task metadata shows the project section wherever project context appears, and archived projects open with their tasks from Archived.
- Desktop can convert a task into a section of its project, convert an inline task to Reference, and export the current filtered list as CSV.
- Task lists and project workspaces can sort by time estimate.
- Priority appears as a colored row strip across desktop and mobile, with dark-theme contrast kept distinct from Waiting.
- Desktop project and board rows support keyboard reordering, expose labelled drag handles, and keep No Section last only when it contains tasks.
- Reference tasks keep their status when duplicated, and duplicated tasks no longer inherit stale focus order, archive history, or attachment identities.
- Project sections can preview one line of notes, while markdown is stripped from tooltips.

## Focus, Review, Calendar & Pomodoro

- Focus previews deferred and recurring work during the seven days before it starts and explains when each item becomes available.
- Review Due appears above Next Actions. A task appears only in its highest-priority section: Today’s Schedule, Review Due, then Next Actions.
- Today includes tasks that start later today, shows their start time, keeps other-day deferrals out, and sorts timed mobile rows by time.
- Today’s Focus accepts a limit of one and shows every starred task counted by the limit, including work hidden by project or area state.
- Mobile Focus starts with details hidden and remembers the local Hide details choice.
- Weekly Review adds a This week look-back at the final step.
- Monthly recurrence supports several month days and RFC 5545’s true last day, while count-limited series show completed occurrence progress.
- Desktop typed dates accept year-less and two-digit-year forms, complete them on blur, and defer invalid announcements until the edit is finished.
- Calendar controls can hide start-date entries, color deadlines by project or area, label period navigation, keep adjacent time blocks distinct, and stabilize mobile week-density changes.
- Pomodoro can alert at session end without enabling task reminders and shows today’s completed focus sessions with a daily reset.

## Sync Encryption & Convergence

- File Sync, WebDAV, and Dropbox can encrypt documents, backups, snapshots, and attachments with a user-held passphrase using the MWENC1 format.
- Encryption can be enabled before the first sync. Devices meeting an encrypted location request its passphrase, and rotation or disable operations resume after interruption.
- Remote mutation fences, provider request bounds, and File Sync leases keep ordinary sync and encryption transitions from racing each other.
- File Sync binds reads, writes, cleanup, recovery, and probes to the retained file or directory identity across Windows, macOS, iOS, Android, and Unix desktops.
- Immutable attachment generations survive replacement, interruption, delayed readers, directory rebinding, cleanup, and crash recovery without allowing a stale writer to replace a newer file.
- Attachment downloads install by exact generation, preserve a local edit that wins the race, and retire missing CloudKit assets without looping.
- WebDAV works with plaintext servers that lack strong ETags when safe compatibility can be proven, requests stored bytes so proxy compression cannot corrupt ETag checks, retries bounded probes, and cleans probe residue.
- Sync encryption and attachment inventory checks fail closed on malformed, unreadable, oversized, incomplete, or conflicting remote generations.
- GTD settings sync by default. No-op cycles retain local file stats and skip redundant whole-document fingerprints, merges, and copies.
- Expo Go keeps plaintext sync available when native crypto and attachment installer modules are absent.

## Attachments, Imports & Data Safety

- Edited attachment content propagates through sync with checksum verification and check-on-touch detection.
- Uploads accept bytes only from Mindwtr-managed storage, downloads have separate size budgets, restore sanitizes paths, and sync errors redact credentials, attachment names, and local paths.
- Removal tombstones keep cleanup from fighting merge, while lagging devices can still read the generation they referenced.
- Mindwtr CSV export and import preserve recurrence rules; import limits, date validation, historical identity lookup, and reference-task normalization reject malformed or ambiguous data.
- Self-hosted cloud reads, writes, calendar feeds, attachment cleanup, and REST mutations return errors instead of replacing unreadable namespace data with an empty store.
- Desktop config, Dropbox credential migration, Obsidian writes, and local API attachment validation retain the last proven state and report failures without exposing secrets.

## Mobile & Apple Integration

- iPhone users can open quick capture from a Lock Screen widget and, on iOS 18, from an Add Task control in Control Center or the Lock Screen controls.
- macOS gains a native Today widget that shares the app’s signed App Group and opens Focus or capture in the desktop app.
- Single-day all-day calendar events stay within the selected day on EventKit platforms.
- Android notification actions survive stale alarm rows; receivers reject unintended callers, context automation has a shared wake limit, and app data stays out of automatic backup.
- Mobile attachment hashing, generation-bound installation, File Sync locking, and background sync teardown use native guarded paths.
- Pull to refresh joins an in-flight sync, queued sync activation explains its state, and Android startup no longer crashes while initializing the remote fence.

## Desktop, Accessibility & Distribution

- Desktop attachment downloads allow their hidden staging file through the filesystem scope on Linux and macOS.
- Linux Quick Add can read clipboard images, X11/AppImage windows use a taskbar-safe 128 px icon, and Flatpak receives the feedback endpoint.
- macOS keeps the app shell from scrolling past the viewport; keyboard help closes from its shortcut; calendar, drag, and reorder controls expose accessible labels.
- The web build shows its real version and hides the desktop updater.
- Release automation validates Apple plists and the optimized macOS Rust/Swift bridge, avoids pipefail false failures, raises Android APK build headroom, and preflights Flathub’s isolated npm workspace install.
- Core, desktop, and mobile FOSS npm locks stay aligned with their isolated release builds, and the FOSS path strips blocked native modules and unused permissions.

## MCP, Cloud & Developer Experience

- The MCP package separates CLI startup from library imports, closes local and HTTP resources on shutdown, serializes cross-process writes, and rejects invalid boolean flags and unsupported write fields.
- Local and cloud MCP modes align actionable views, search operators, UTC date buckets, limits, error wording, and service behavior.
- MCP real-SQLite and cross-process suites use explicit budgets for shared CI runners.
- Self-hosted setup explains the no-account token model, documents multi-token use, and distinguishes the cloud service from the local app.
- Desktop development warms the Settings module graph, shared store paths avoid dead derived-state work, and performance tests cover large-list bulk mutation and sync trace costs.

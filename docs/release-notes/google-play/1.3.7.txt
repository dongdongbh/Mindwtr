<en-US>
Projects get a Per section flow mode. Set default task reminders, tick Reference checklists, sort by Priority, give projects a color and try Gruvbox themes. Tap a context to switch, long-press to combine; nested contexts group. Widgets add date filters, Upcoming previews, direct context picks, a Contexts button and capture descriptions. App Lock can wait before asking. Background sync sets reminders, and sync keeps other devices' changes. File Sync works with more storage apps.

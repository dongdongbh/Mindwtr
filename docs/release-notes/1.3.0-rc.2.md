# Mindwtr 1.3.0-rc.2

This release candidate fixes launch, capture, archive, and notification failures found after rc.1. It also includes the desktop workflow and performance work now on main.

## Fixes to verify

- macOS launches on Intel and Apple silicon with packaged Swift runtime libraries resolved by the app; widget and native setup still load.
- Shortcut and Action Button capture opens one confirmation form per delivery, including cold and warm launches.
- Apple Watch text and audio captures survive outbox-save failures and can be resent without replacing pending work.
- Archived and cancelled project data and mobile cancellation drafts retain edits, references, section links, and terminal outcomes after restart and sync.
- Android quick capture restores keyboard readiness, and delayed Pomodoro alarms remain available for system delivery.
- Dropbox OAuth callbacks use bounded blocking reads on BSD and macOS sockets.
- Project section fields remain visible in mobile and desktop editors for saved layouts.

## Other changes

- Create projects from task quick actions and bulk-organize flows.
- Export selected desktop tasks to CSV from bulk selection and the shared More menu.
- Configure AI request timeouts; timed-out and cancelled requests stop without terminal retries.
- Focus groups later-today tasks, desktop Today keyboard order matches display order, and Settings, capture, full-sync, and storage paths do less repeated work.
- WebDAV activation handles attachment checks in bounded batches, while File Sync streams attachments with safer permissions.

## Testing focus

- Upgrade from 1.2.8 or rc.1 and exercise task capture, editing, completion, cancellation, archive, reopening, and sync with other clients.
- On macOS, relaunch, connect Dropbox, use the widget, and inspect Diagnostics for `v1.3.0/macos-swift-runtime` and `v1.3.0/dropbox-callback-stream`.
- On iPhone and Apple Watch, repeat shortcut capture and retry offline text and audio Watch capture after reconnecting.
- On Android, open capture from a widget, shortcut, and Quick Settings, confirm the keyboard is ready, and finish a Pomodoro with delayed alarm delivery.
- On WebDAV or File Sync, activate against attachment-heavy data, then verify another client receives the same attachments.

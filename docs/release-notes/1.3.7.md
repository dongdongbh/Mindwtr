# Mindwtr 1.3.7

Mindwtr 1.3.7 adds a Per section flow mode for projects, default task reminders, checkable Reference lists, Priority sorting, project colors and Gruvbox themes. Contexts are easier to switch and nest, widgets gain date filters and Upcoming previews, and sync keeps more of what other devices changed.

## Highlights

- Projects have a **Per section** flow mode: each section is Parallel or Sequential, so one section moves step by step while another offers all its tasks at once. (#1429)
- **Default task reminders** choose Send or Skip for new tasks, and each task can use the default or override it. (#1383)
- Reference items have **checkable lists** with Reset checklist, and a repeating task can keep its checked items for the next occurrence. (#1416, #1400)
- Task lists can sort by **Priority**, projects can have their own **color**, and two new themes arrive: **Gruvbox Light** and **Gruvbox Dark**. (#1415, #1422, #1426)
- In Contexts, a **tap switches** to a context and a long-press or Ctrl-click combines. Nested contexts such as `@person/todd` show as groups, quick add reads them as one token, and saved contexts and tags stay available when no task uses them. (#1427, #1428, #828)
- Widgets gain **Task dates** filters (Next 7, 14 or 30 days, All upcoming), **Upcoming** previews, and on Android direct context and tag choices, a Contexts button and pre-filled capture. (#1408, #1396, #1399, #1418)
- Sync keeps what other devices changed: open editors, settings pages and edits made during a sync no longer put back older values, a saved change uploads within seconds, and File Sync on Android is much safer with storage apps. (#1430, #1431)
- Desktop MCP has separate permissions for edits, archiving and deletion, a configurable port, and **Copy for Codex**. (#1337)

## Projects, tasks and Focus

- Projects have a third Flow mode, **Per section**: each section is Parallel or Sequential. Sections never wait for each other, and tasks with no section are Parallel. Set it in a section's menu on desktop or in **Sections** on mobile. Older app versions show such a project as Parallel. (#1429)
- A sequential project can be converted into a section of a project set to **Sequential → Within sections**, and the new section keeps its task sequence. (#1324)
- **Settings → Notifications → Default task reminders** chooses Send or Skip for new tasks. Each task has **Start/due reminders**: Use default, Send or Skip. Existing tasks keep their previous behavior until you choose Use default. (#1383)
- A Reference item's list has checkboxes on desktop and mobile. A ticked entry is struck through, and **Reset checklist** unticks them all. Ticking every entry never marks the reference done or puts it in Focus. Pasted `- [x]` lines keep their tick. (#1416)
- A repeating task can keep its checked checklist items for the next occurrence: turn off **Reset checklist for the next occurrence**. (#1400)
- Task lists on desktop and mobile can sort by **Priority** (highest first, tasks without a priority last), while Priorities is on. It is not offered as a project's own sort or in Done and Archive. (#1415)
- Focus and saved-filter sorts by due, start, review or time estimate fall back to the next sort key when both tasks lack the value. (#1415)
- Projects can use their own color instead of the Area color. (#1422)
- Today's Focus follows the Area selection and says how many selected tasks are in other areas. (#1421)
- Filters have a **Task dates** condition: Today, Next 7 days, Next 14 days, Next 30 days or All upcoming, matched on start, due or review date. (#1408)
- Saved filters with legacy Inbox and Done tokens read correctly.

## Contexts and quick add

- Tapping a context or tag switches to it. To combine several, long-press a chip on mobile, or Ctrl-click (Cmd-click on macOS) on desktop. (#1427)
- A nested context such as `@person/todd` that follows its parent `@person` shows as `/todd`, so a family of contexts reads as one group. The full name stays in tooltips and for screen readers. (#1428)
- Quick add reads `@person/todd` and `@"Two words"` as one context or tag, even when no task uses it yet. (#1428)
- Contexts and tags you add stay available in pickers and suggestions when no task uses them. (#828)
- Mobile Contexts has a Sort button beside its search, as in Inbox. (#1415)
- Desktop task input suggests the `/estimate:` command.

## Themes and languages

- New **Gruvbox Light** (soft) and **Gruvbox Dark** themes on desktop and mobile, with status and accent colors darkened where needed so text stays readable. (#1426)
- Review scope strings are translated to Portuguese (Brazil), and Chinese text uses Chinese commas. (#1420, #1378)
- An invalid system locale no longer breaks date formatting.

## Widgets and capture

- Widgets can filter by Task dates and show an **Upcoming** preview with start and return dates, on Android and iOS. (#1408, #1396)
- Android: a Tasks widget picks its context or tag directly from a list. (#1399)
- Android: a widget that shows one context or tag opens quick capture with it already typed in. The capture window also has a **Contexts** button with a short searchable list. (#1418)
- Android: widget capture inherits an editable status from its task widget. (#1418)
- Android quick capture has a description field beside the title and audio. (#1406)
- Android: quick capture waits for its window before focusing the title. (#1347)
- Android: when a Tasks widget switches to a saved filter, context or tag, Mindwtr fills it the next time the app opens, even if no task changed.

## Mobile

- App Lock has a **Require unlock** choice: Immediately, After 1, 5 or 15 minutes. Immediately stays the default, and a cold start always asks. A restore keeps this phone's App Lock on. (#1423)
- iOS: an optional **App icon badge** counts tasks due today and overdue. (#1387)
- iOS: **Dismiss** on a reminder no longer opens the app. (#1386)
- iOS: a sync running when you switch to another app finishes in the background. If iOS ends the time first, the change stays pending and uploads when you return. (#1432)
- Android: reminders for tasks synced from another device are set by the background sync, even when Mindwtr was swiped away. Reminders are also set after a background capture. (#1424, #1398)
- Android: Back leaves multi-select in task lists, projects, Contexts, Review and Trash before leaving the screen. The Contexts selection bar uses the same X and compact buttons as Inbox. (#1415)
- The task editor closes when you navigate away without changes, and task rows honor a hidden Status field. (#1410, #1405)
- Project sort applies to reference tasks, and the Weekly Review sheets close before navigating. (#1401, #1391)
- Task details offer the task link and ID copy actions. (#1368)
- A Calendar week with a deadline opens on the selected day.
- Calendar and the reviews read synced calendar subscriptions before Settings › Calendar is opened. Android keeps a picked local `.ics` file readable after a reboot.
- Pomodoro keeps credit and auto-start preferences when a session expires, and its task link refreshes after a status change.
- Turning off "Expose to system search" on Android removes Mindwtr's items even if the app closes or the removal fails, or the switch goes off during a rebuild.

## Desktop

- The pop-up task editor gives Details more room in wide windows and stacks in narrow ones. You can paste images into a description. (#1381)
- Task menu submenus (Dates, Move to, Contexts, Priority) open on a deliberate hover. (#1390)
- Timeline shares project and task order with Projects, with a reorder handle and keyboard reordering. (#1362)
- Daily Review's Focus cards show start and due dates, and Weekly Review can complete a project in place. (#1385, #1395)
- A link in a task's collapsed description preview opens when clicked. (#1425)
- Linux: Copy Title, Copy task link and Copy task ID no longer fail now and then with "Could not copy task". (#1327)
- Linux: task links open from deb, rpm and other package launchers. (#1377)
- The HTTP sync warning can be dismissed per device and destination. (#1397)
- Desktop dependency security updates (rustls, quinn-proto), and desktop HTTPS certificate checks no longer trust distrusted intermediate certificates (rustls-webpki 0.103.16, webpki-roots 1.0.10).

## MCP and Local API

- Desktop MCP has separate switches for edits, archiving and deletion, a configurable port, and **Copy for Codex** connection details. (#1337)
- MCP reloads a database that was created after it started, and the `mindwtr-mcp` package is 1.1.13. (#1429)

## Sync, backup and import

- Two devices that auto-archive the same task no longer conflict. (#1430)
- A task saved right after a sync uploads a couple of seconds later, and the sync dot stays amber until the upload finishes. (#1431)
- Settings pages, saved filters, the task editor, Process Inbox and the project sheet save only what you changed. Lists (tags, contexts, checklist items, attachments) merge item by item, so nothing another device added or removed is lost.
- An edit made while a sync was saving no longer overwrites what another device had just synced. Undo of an Inbox decision is refused when another device changed the task since.
- An attachment another device changed is no longer overwritten by this device's older copy when its download is delayed.
- Undo after a restore, merge or import brings attachments back with their files while the app stays open. A restore also marks attachments whose files are missing, so the next sync downloads them.
- Android File Sync: storage-app errors (a folder it cannot list, a file read in part) stop the sync instead of being read as empty or damaged data. Picking a folder no longer creates an empty `data.json` or a duplicate. Storage apps that identify files by number, and rclone (RSAF) attachment uploads, now work. (#1001)
- File Sync (Android and iOS): a missing or damaged sync file with an earlier copy still in the folder stops the sync as a conflict instead of being rebuilt from this device. The backup file is replaced by a new file, never rewritten in place.
- Mobile backups: a recovery snapshot survives a clock moved back; an oversized snapshot is refused before it is read; a backup cut short in a picked Android folder is deleted later; failures show their own words; Getting Started blocks restores while it saves.
- Imports: a ZIP whose recorded sizes do not match its contents is refused as damaged. CSV import warnings name skipped columns and date cells.
- Self-hosted Cloud closes a connection after refusing a request it did not read in full. Browser (web) task attachments upload to self-hosted Cloud. (#1419)

## Security and privacy

- Android: a file shared into Mindwtr is copied under a generated name, and only another app's content link is accepted, so a malicious app cannot overwrite or attach Mindwtr's private files.
- Android: release builds no longer include the Compose preview launcher, a debug tool that could start screens by name.
- Logs redact local file and document paths under phone storage, and File Sync log lines carry error codes instead of raw error text.

## Feedback, onboarding and diagnostics

- Sending feedback without a reply email asks first, because Mindwtr has no account email to reply to.
- Getting Started teaches a manageable Focus list. (#592)
- Diagnostics add release checks for this version's sync, reminder, App Lock, widget and backup changes, and keep earlier unconfirmed checks.

## Native mobile development ports

- Stable mobile releases continue to ship the production React Native app. The Android Compose and iOS SwiftUI clients remain development ports.
- Native iOS adds Board moves, completion and ordering with Undo, Inbox filters, sorting, grouping and durable bulk organize, Process Inbox Undo, Reminders import, Pomodoro controls, and AI settings.
- Native Android adds Settings › Data backups, restores, merges and imports with a size-scaled transfer limit, Settings › Calendar, file share capture, and the widget list screen.
- Core takes over more shared rules from React Native (File Sync IO, recovery snapshots, AppSearch, last-screen restore, Pomodoro and Reminders), byte-identical, so the native apps behave the same.

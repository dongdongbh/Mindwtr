# Mindwtr Unreleased

Changes collected after `v1.1.6` and before the next version tag.

## Highlights

- Mobile (Android): a new opt-in "Expose to system search" setting (Settings → General → Privacy, off by default, Android 12+) lets your device's system search find Mindwtr tasks, projects, and areas by title. Only titles and minimal status/due/project metadata are indexed — never descriptions, notes, or attachments — the index lives on the device, and nothing leaves it. Tapping a result opens the item in Mindwtr; turning the switch off removes everything from the index. (#1017)

## Full Change List

- Themes: added Catppuccin Macchiato and Dracula dark themes, selectable in Appearance settings on desktop and mobile (synced across devices like the existing themes).
- Process Inbox: turning a captured item into a project no longer fails on the first attempt with "Failed to save task: FOREIGN KEY constraint failed" — the task write could reach the database before the just-created project it points at; the two now land together. Desktop and mobile. (#1024)
- Desktop: changing the sidebar area filter while a sync is running no longer snaps back to the previous selection when the sync finishes — the sync now notices the mid-sync change and re-runs instead of writing the older value back over it. (#316)
- Mobile (iOS): deferring a task from Focus with "Defer until → Custom…" no longer crashes the app on iOS 26 — the inline calendar aborted when its earliest-selectable-date limit was applied. Past dates picked in the calendar are still bumped to tomorrow, now inside the app instead of by the calendar control.
- Quick add: the capture inputs now show what the parser recognized as you type — resolved dates, project, area, contexts, tags, and a warning when a date command can't be read — on desktop and mobile.
- Desktop and mobile: when your latest changes cannot be written to storage (for example a full disk or an unavailable drive), Mindwtr now shows an alert with a Retry button instead of failing silently — the unsaved changes stay in memory until a retry succeeds.
- Mobile (iOS): recurring task reminders no longer pile up duplicate notifications over time — cancelling a previously scheduled reminder was silently failing, so every edit, sync, or occurrence rollover left the old notification pending. One already-accumulated burst may still fire once after updating; counts stop growing from then on. (#1020)
- Recurrence: completing a repeating task late no longer creates a next copy whose start date sits after its own due date — start, due, and review dates now move forward together, keeping the gaps you set between them, and the new copy is never already overdue the moment it appears. Desktop and mobile.
- Task editor: the Person field now appears automatically while a task is edited as Waiting For, so an existing task can be assigned to someone without first customizing the editor layout. Desktop and mobile. (#1021)
- AI Copilot: suggestions now apply one piece at a time — tap the suggested context, time estimate, or any tag on its own, or apply all of them at once. Works in the task editor, the desktop list's add-task row, and mobile quick capture. (#1022)
- Desktop: task rows no longer send background AI Copilot requests just by being on screen — with AI enabled, every visible row used to issue its own suggestion request on mount and again while scrolling. Suggestions now run only for the task actually being edited, cutting unrequested API usage and provider cost.
- Desktop: AI Copilot suggestions no longer silently fail to appear when the editor re-renders shortly after opening — a task opened straight into editing could permanently skip its suggestion request.
- Desktop: when watching the data file fails at startup (a network or virtual drive that answers late), Mindwtr now logs it and tries again when the window regains focus — external edits from the CLI, MCP, or another tool were previously unnoticed until restart.
- Desktop: the window no longer freezes at the start of each sync while the safety snapshot is written, and search stays responsive while the search index answers — most noticeable when the data folder lives on a network or virtual drive (rclone, WinFSP).
- Desktop: reading and saving settings, credentials, calendar entries, and macOS system-calendar events no longer runs on the thread that draws the window — slow disks, the OS keyring, and EventKit can no longer cause brief window freezes, and a test now prevents new commands from reintroducing the pattern.
- Process Inbox: the guided clarify step now offers the AI clarify action when the AI assistant is switched on. Desktop. (#1022)
- Desktop: refreshing the sync backup no longer logs a write error on rclone and WinFSP mounts — the backup copy no longer sets the destination's size, which those mounts refuse without a write cache. The backup itself was already updating correctly. (#1001)
- Desktop: File Sync no longer logs a write error against its lock file on rclone and WinFSP mounts — taking the folder lock needs no write access, so an existing lock file is now opened read-only. Sync was already correctly locked there; only the mount's log was affected. (#1001)
- Desktop: checking for updates no longer fails with "GitHub API error: 403" on shared networks or VPNs — when GitHub's API rate limit blocks the check, the app now reads the public release feed instead, and at worst shows a calm try-again message with a link to the releases page.
- Desktop (macOS): with "close to tray" enabled, the app no longer vanishes from the Dock, Cmd+Tab, and its own menu bar while the window is open. It now steps out of the Dock only while actually hidden in the tray, and comes back focused — with its menu bar — the moment the window is shown again.
- Desktop (macOS): the global quick-add hotkey no longer brings the main Mindwtr window forward — the capture popup is now a non-activating panel, so the app you were working in stays active while you type, and keeps focus after you press Enter or Escape. (#794)
- Desktop: sync-conflict, search, archive, Obsidian and project-duplication messages now appear in your language instead of always English, and duplicating a project confirms it the way mobile already did.
- The language picker now marks a language as "Partly translated" when much of the app is still English in it, so an unfinished translation is visible before you switch. Desktop and mobile.
- Imports, restores, and merges can now be undone straight from the result message — one "Undo import" tap rolls back to the recovery snapshot taken just before, instead of hunting for its name under Settings. Desktop and mobile.
- All platforms: Settings → Data can now export your tasks as a Mindwtr CSV file — open it in a spreadsheet, share a readable copy, or take your data to another app. Re-importing an export recognizes the exported IDs, so it never duplicates your tasks; rows for tasks that already exist are skipped rather than edited. (#1011)
- MCP automation: task searches now understand the same operator language the app search box does (status:, context:, tag:, due:<=7d, quoted phrases, -negation), and MCP clients can ask for genuinely available work with a new view filter that separates actionable tasks from ones deferred to a future start date or waiting behind an earlier step of a sequential project.
- CLI automation: the list command no longer silently stops at 200 matches when filtering with a search query — it now prints every matching task.

- Calendar: a task with a start date but no time now shows "All day" in the desktop month grid and the mobile schedule list, instead of a phantom midnight time (shown as "12:00" on 12-hour clocks).
- Desktop: attachment links pointing at a folder (for example `D:\Media\Movies\`) now open in the file manager instead of failing with "Path is outside Mindwtr-managed locations". Links to files anywhere already worked; folders now match.
- Desktop: the sync backup file (`data.json.bak`) now updates on rclone and WinFSP mounts that refuse in-place overwrites — it is written to a temp name and renamed into place, the same way the data file itself is. Previously the backup silently stopped updating there. (#1001)
- All platforms: Settings → Data can now import a generic "Mindwtr CSV" file (or ZIP of CSVs) — a documented spreadsheet format covering titles, descriptions, statuses, projects, sections, areas, contexts, tags, assignees, priorities, energy, start/due/review dates, completion, checklists, and manual order — so migrations from apps without a dedicated importer no longer lose structure. (#1011)
- All platforms: Settings → Data now folds the Data Transfer list (backup, restore, and the importers) behind its heading, so the page opens as a short summary instead of ten rows. Tap or click the heading to open it; searching for a setting inside still jumps straight to it.
- All platforms: the app reaches its first screen faster from a cold start, most noticeably on mobile — startup no longer builds all 20 language dictionaries before drawing anything, and loads only the handful of getting-started strings the first-run seed needs.
- Desktop: pressing Enter in the context menu's Start Date, Due Date, Review Date, Area, and Contexts panels now saves the value and closes the dialog, matching the task editor. (#992)
- Mobile: adding a task from a project opened via the Projects tab returns to that project again instead of dropping back to the projects list. (#766)
- Desktop: Windows sync verifies TLS through the Windows certificate engine again, so setups behind corporate TLS interception (for example Zscaler) sync like they did before 1.1.6. macOS and Linux keep the 1.1.6 TLS 1.3 support. (#663)

- Calendar: typing a task into a calendar slot now reads your text the same way quick add does — a multi-word context, tag, or person you already use (`@John Smith`, `%Jim Smith`) is recognized whole instead of stopping at the first space, and date commands pick up your default scheduled time. Desktop and mobile, and the same recognition now applies to tasks added through the self-hosted server's API and the automation script.

- Mobile: when a device's secure keystore is unavailable, sync tokens and passwords are now held in memory for that session only instead of falling back to ordinary app storage — any credential left in the old location is removed the first time it is read, so you may have to enter it again after a restart. - Mobile (iOS): the app no longer quits unexpectedly while moving between screens, closing a modal, or shutting down. Every crash report collected from 1.1.0 and 1.1.5 came from one cause — a React Native self-check aborted the app while describing a view-index mismatch it was only supposed to log — and Mindwtr now finishes removing the view and carries on. - Desktop: the Pomodoro timer now finishes wherever you are in the app. The clock only ran while the Focus view was on screen, so a session started and then left behind — the point of the timer — never reached zero and never played its sound, notification, or taskbar flash until you came back to Focus. - Self-hosted cloud server: revoking a token now also stops its published calendar feed — the feed URL previously kept working forever, since only the token being revoked could reach the authenticated endpoint that would have stopped it.
- Dutch: the daily digest and weekly review notifications are written in Dutch instead of falling back to English titles.
- Notifications: a digest line whose translation a language does not carry now falls back to the English text instead of showing "undefined" — most visibly the Focus line in Italian and, before this release's translations, the Dutch digest titles.
- Desktop: moving a task between projects or areas and deleting a project can now be undone with Ctrl+Z — neither registered an undo before — and both now show the same Undo toast as list actions.
- Mobile: large libraries no longer get occasional "Sync issue" alerts while tasks are being added and completed — the database read at the start of a sync was cut off after 3.5 seconds, a fail-fast meant to switch to a backup copy that oversized libraries don't keep; with no backup to switch to, the read now gets the time it needs instead of failing the sync. The next sync always recovered on its own; only the alert was wrong. (#766)
- Sync: libraries with permanently deleted tasks now settle completely after a sync — one remaining path still re-stamped every deletion marker's revision on each cycle, rewriting thousands of database rows per sync and immediately queueing the next one, so sync ran back-to-back in the background on large libraries. This was the leftover churn behind the remaining slowness and order-revert reports on Android. Desktop and mobile. (#766)
- Desktop: the "Send request…" button in Process Inbox's delegate step now does something — clicking it used to silently do nothing in the desktop app. When the chosen person's reference link is a mailto: address, your mail app opens with the request addressed to them; otherwise the request text is copied to the clipboard, ready to paste into any email or chat. Mobile already offered the system share sheet and is unchanged. (#1022)
- Mobile (Android): syncing to a folder served by a storage provider that never declares write support — such as RSAF (rclone) — no longer fails every sync with "Re-select the sync file or folder" after setup succeeded. Writing the sync file used to trust the provider's writability metadata; it now attempts the write directly when that metadata says no. (#1001)
- Desktop: checklist checkboxes keep their square shape in narrow windows — in expanded task rows and the task editor they could squash into ovals when the row ran out of width, the same way the settings toggles once did. (#858)
- Mobile: the image attachment preview now has a Share button, so a photo can be handed to the gallery or any other app to view it full-size and zoom — the in-app preview itself stays a quick glance. In the task editor and the project attachments list. (#1026)
- Desktop: the OLED / Midnight theme is now in the desktop theme picker too — the same pure-black backgrounds the mobile app already offered for OLED screens. A theme choice of OLED synced from your phone now renders as OLED on desktop instead of falling back to regular Dark. (#1025)
- Mobile: task lists can group by context now, matching desktop — References, Inbox, Done, and Archive gain the axis; a task with several contexts appears under each of them, and tasks without one collect in a "No context" group at the end. (#1027)
- Mobile (Android): self-hosted sync behind a private certificate authority now works once that CA is installed on the device — the app trusts user-installed certificates, the way desktop already honors the operating system's certificate store. Before, the connection check failed during setup and later syncs confusingly reported "Self-hosted URL not configured". (#663)
- Mobile: the project view's "Show completed" choice is remembered across app restarts on this device, matching desktop — it previously reset to hidden every time the app was closed. (#1030)
- Mobile: after "Save & edit" on a captured task, backing out of the editor no longer lands on the capture form again with the already-saved text still in it — the capture screen now steps aside when it hands off to the editor. (#1029)
- All platforms: Settings → Data can export your tasks as TaskNotes files — one Markdown file per task with YAML frontmatter, packed as a ZIP, ready to drop into an Obsidian vault for the TaskNotes plugin. Statuses, dates, contexts, project, tags, time estimates, and descriptions carry over, and Mindwtr's own Obsidian import reads the files back. (#1031)
- Mobile: after "Save & edit" on a task captured from a project, leaving the project no longer takes an extra Back tap past a flickering duplicate of the project page — the editor now opens on the project screen that is already there instead of stacking a second copy of it. (#1029)
- Mobile: tapping Done in Task order mode now keeps the list where the reorder view was — after dragging a task to the top, the list stayed there instead of jumping back to where you were before entering reorder, which made the move look like it hadn't stuck. (#784)
- Desktop (Linux): with Appearance set to System, the app now reads the desktop's dark preference from the XDG settings portal — the standard signal every desktop provides — instead of GNOME-only settings, so KDE Plasma with a dark color scheme starts dark. Where no portal answers, a dark-named Plasma color scheme (like Breeze Dark) is still recognized. (#989)
- Desktop: opening search (Cmd/Ctrl+K) while viewing Done or Archived now includes finished tasks from the start — searching the list you are looking at no longer comes back empty. The "Include Done and Archived tasks" filter still covers every other view. (#1019)
- Calendar: in the month grid and the week view's all-day row, one-off tasks and events now claim a day cell's few visible lines before projected recurring occurrences — a daily recurring block no longer pushes a unique appointment into the "+N more" overflow. Desktop and mobile.
- Search: the result list no longer flashes and reshuffles while you type. Text still being composed through an input method (Chinese pinyin, Japanese kana) is no longer searched before it is committed, so results don't blink to "no results" between characters on desktop; and on desktop and mobile, index matches that answered an earlier keystroke no longer jump ahead of the current results while you keep typing.
- Mobile: connecting Dropbox now turns sync on by itself once the first sync succeeds. On Android, returning from the Dropbox sign-in page could silently discard the just-granted access before anything was saved, so the app said "Connected" while Settings → Sync stayed Disabled and the account showed as unauthenticated on the next visit. The first sync now runs immediately after signing in, and the configuration is saved the moment it succeeds. (#1034)
- Desktop: when new sync settings fail their verification sync, the toast now includes the actual error underneath "Sync setup could not be verified" — a folder that refuses writes or a server that times out names itself instead of leaving you guessing. (#1001)
- Desktop: File Sync now notices when an attachment file is missing from the sync folder and copies it back in on the next sync. Pointing File Sync at a new folder used to leave the attachments directory empty forever unless the change was made through the settings screen's verify step. (#1001)
- Desktop: changing the File Sync folder works again — the verification sync checked attachments in the new folder before the app had granted itself access to it, so every folder change failed with "forbidden path" and the previous settings stayed active. (#1001)
- Desktop: hovering an attachment now shows its full path, and opening one whose file has gone missing says which path was tried instead of a bare "File does not exist or cannot be accessed." — the two clues needed to repair a moved file or a relocated portable profile. (#1001)
- Desktop: a task row's hover buttons (Start focus session, More options) no longer show through an open toolbar menu — in Review, hovering a task behind the View panel made its buttons visible and clickable through the menu. (#1040)
- Mobile: the "Task deleted — Undo" toast no longer covers the tab bar — it now appears just above it, and drops its redundant "Notice" heading, so deleting or completing a task with a swipe leaves the bottom navigation visible and tappable. It still dismisses on its own or with a sideways swipe. (#1044)
- Desktop (Linux): sync can now be set up on systems with no working keyring — a sandboxed Flatpak on a machine without a Secret Service used to fail every WebDAV or self-hosted save with "credential authority is unavailable" and drop the sync method back to Off, even though the connection test passed. The password or token is stored in the app's private secrets file instead, with the usual warning that it is not encrypted there. Re-entering a password or token also recovers a setup whose keyring stopped answering after it was saved. (#1043)
- Task editor: checklists no longer keep the empty row that Enter (or the return key on mobile) creates while typing a list — blank items are dropped when you leave the checklist on desktop and when the task is saved on mobile, so a five-item list stays five items. (#1045)
- Desktop (macOS): the Pomodoro completion chime now actually sounds when the session ends while you work elsewhere — macOS only lets the app make sound in response to a click, so the chime is now readied at the moment you press Start and reused when the timer hits zero. Windows and Linux were already audible; they use the readied path too. (#528)
- Desktop (macOS): the search panel no longer lets the system capitalize or autocorrect what you type — queries are partial words and operators like `status:done`, and macOS treated the field as prose when automatic capitalization was on. Prose fields like the task description still follow your system's setting. (#1019)
- Desktop: attachments the app holds a copy of now open after a portable install moves. Every stored attachment path is absolute, so relocating the profile (new drive letter, renamed folder, another machine's USB mount) left every attachment reporting "File does not exist or cannot be accessed" even though the file travelled along inside the profile. Opening, previews, sync and cleanup now fall back to the same file name in the profile's current attachments folder when the recorded path is gone. (#1038)
- Desktop: adding a local file through "Add link" (or "Link to file…") now really is a pointer. Such a link was recorded as a file attachment, so sync uploaded a copy of the original into the sync folder and, once the original moved, replaced the link with that copy — the opposite of what a link promises. Existing attachments are unchanged; re-add or edit the link to convert one into a pointer. (#1001)

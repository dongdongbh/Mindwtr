# Mindwtr Unreleased

Changes collected since the latest stable release.

- Mobile and desktop: a task saved as one web link takes the page's title, Wikipedia pages included. A Privacy setting, Look up page titles, turns these lookups off. (#1606)

- Mobile: the task editor's Edit/Preview highlight now covers exactly one half of the switch. In Bulk organize, a long Apply label now wraps at large font sizes instead of cutting off Cancel.

- Mobile: Weekly Review, Daily Review and project calendar links keep calendar-file (ICS) events when the device calendars cannot be read, and show a warning with them. Before, one device calendar error hid all calendar events there. (#1578)

- AI Clarify and task editor suggestions can offer an existing Area for an unassigned task. Choose the Area to apply it to the draft. (#1608)

- Snap: remote sync no longer reports the app as Offline when the system network is available, so Self-hosted, WebDAV, and Dropbox sync can be configured and run again. (#1612)

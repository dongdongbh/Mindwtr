# Mindwtr 1.2.5-rc.2

This release candidate hardens file-based sync and attachment publication, fixes first-sync encryption setup, and adds focused GTD workflow improvements across desktop and mobile.

## Highlights

- Set up sync encryption before the first sync so plaintext never reaches File Sync, WebDAV, or Dropbox; first contact with an already encrypted location now asks for its passphrase.
- Organize Someday/Maybe with named sections that sync across devices, and see project-section context wherever tasks appear.
- Process Inbox one question at a time on mobile or use the compact Quick flow; desktop and mobile processing now understand the same quick-add syntax as capture.
- See Review Due in Focus before Next Actions, keep each task in only its highest-priority section, and preview tasks that start later today in Upcoming.
- Export the currently filtered desktop list to CSV, capture directly to Reference with `/reference`, and hear Pomodoro session-end alerts without enabling task reminders.

## Reliability and security

- File Sync and attachment publication now retain exact file and directory identities across replacement, cleanup, and recovery, preventing raced readers or writers from adopting the wrong generation on Windows, macOS, iOS, Android, and Unix desktops.
- Downloads that race a local attachment create or edit preserve the local generation instead of overwriting it; removed shared generations remain available to lagging devices.
- WebDAV compatibility checks fail closed when the server cannot provide the conditional-write behavior needed for safe multi-device sync.
- Android no longer crashes at startup while initializing the remote sync fence, and self-hosted mobile setup can verify attachments that must first be downloaded from the server.
- Large-library sync avoids redundant full merges and copies when saved and in-memory revisions already agree.

## Testing focus

- Upgrade two devices from `1.2.5-rc.1`, then create, edit, replace, remove, and concurrently change attachments over File Sync, WebDAV, Dropbox, iCloud, and self-hosted cloud where available.
- Test File Sync on Windows, macOS/iOS, Android, and Linux, especially interrupted publication, folder replacement, lock contention, and recovery after a crash.
- Enable encryption before the first sync, connect to an already encrypted location, enter a wrong passphrase, rotate the passphrase, disable encryption, and confirm the next aligned sync is a no-op.
- Create, rename, reorder, assign, and delete Someday sections on desktop and mobile, then verify older clients preserve the assignments they do not understand.
- Exercise guided and Quick Inbox processing, quick-add syntax, `/reference`, filtered CSV export, Focus ordering, later-today Upcoming tasks, and Pomodoro alerts.
- On Android and iOS, open common attachment types in external viewers and verify background/queued sync remains bounded during long cycles.

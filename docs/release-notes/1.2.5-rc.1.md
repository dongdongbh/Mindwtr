# Mindwtr 1.2.5-rc.1

This release candidate adds encrypted file-based sync, richer recurrence, native Apple widgets, and substantial sync, attachment, and large-library safety work.

## Highlights

- Encrypt File Sync, WebDAV, and Dropbox data with a passphrase, including sync documents, backups, snapshots, and attachments. Update every device before enabling it; the passphrase cannot be recovered.
- Schedule monthly recurrence on multiple days or the true last day of the month, and see progress for count-limited series.
- See upcoming deferred and recurring work in Focus during the week before it becomes available.
- Capture from the iPhone Lock Screen or Control Center, and view today's focus tasks in Mindwtr's native macOS widget.
- Keep edited attachments current across devices, verify their checksums, and clean up removed copies without resurrecting conflicts.
- Use faster large libraries, localized natural-language dates, clearer desktop calendar and status controls, and inline mobile checklist capture.

## Reliability and security

- Sync and restore paths now reject corrupt, oversized, partial, or unsafe data instead of silently replacing healthy content or following attachment paths outside Mindwtr's storage.
- Self-hosted Cloud reads, writes, calendar feeds, and cleanup fail closed when stored data cannot be read.
- Android notification and automation receivers accept only intended callers, app preferences stay out of automatic backup, and reminder actions survive stale alarm rows.
- Desktop config recovery, logging, File Sync on lockless filesystems, and no-op SQLite refreshes are more resilient.
- MCP local and Cloud modes now agree on actionable views, search operators, date ranges, write fields, errors, and clean shutdown behavior.

## Testing focus

- Upgrade every device before enabling sync encryption, then test the correct passphrase, a wrong passphrase, a missing passphrase, rotation, attachments, backups, and a second sync that should be a no-op.
- Exercise monthly recurrence on several days, Last day, COUNT and UNTIL limits, and series whose start and due dates use different anchor days.
- Edit, replace, duplicate, and remove attachments across two devices and each supported file-based backend; verify updates propagate and shared files are not deleted early.
- On iOS, test Lock Screen capture, the iOS 18 control, calendar all-day events, File Sync picker recovery, reminders, and shutdown or restart during database work.
- On macOS, add the native widget from the gallery, open Mindwtr from it, and verify its Today payload updates after task changes.
- On Android, leave a reminder overnight, then use Complete, Snooze, and Dismiss; also test context automation rate limiting and a FOSS build's patched dependencies.
- On desktop, test typed dates, calendar Starts visibility, project and status colors, quick-action menus, config edits, File Sync on a virtual mount, and large-list bulk actions.

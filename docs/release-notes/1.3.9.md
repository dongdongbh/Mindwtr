# Mindwtr 1.3.9

## Highlights

- Keep partial Pomodoro work in Time Spent when you pause, switch tasks, or complete a task elsewhere.
- Choose reminder times for date-only tasks, or send only the Start or Due reminder with an optional advance time.
- See capture destinations before saving, with caret autocomplete and reliable destinations for queued text and audio.
- Link a read-only calendar commitment to a project and see recently completed tasks from your current Inbox session.
- Organize multiple Focus tasks, copy task details, and read relative schedule dates at a glance.
- Keep edits made during sync, recover deferred uploads automatically, and avoid repeated Self-hosted settings syncs.
- Upgrade encrypted sync to a stronger format, with safer attachment opening and App Lock startup.
- Use expanded Local API/MCP task lifecycle tools and an API-only MCP container.

**Encrypted sync requires an upgrade:** update Mindwtr on every device first. On one device with a complete, saved local copy, open Settings › Sync › Encryption, choose **Upgrade sync encryption**, and enter your passphrase. Until then, sync pauses with an older-encryption message. Older apps cannot read upgraded files. Keep a separate local backup and retain your existing encrypted recovery copies and their passphrase. Self-hosted Cloud users should update the server alongside the apps.

## Capture and tasks

- Show the chosen project or area during quick capture; list areas before projects and offer suggestions at the caret.
- Preserve admitted destinations for queued text and audio, apply the default area to widget captures, and retain captures whose destination is no longer available.
- Add `/remind-due:` and `/remind-start:` advance reminder syntax alongside timed quick-add dates.
- Treat hex-looking `+project` names as names in empty libraries; leave unmatched `!area` syntax visible instead of linking missing areas.
- Show tasks completed during the current Inbox session, and clarify processing counts and destination navigation.
- Save and complete tasks directly from mobile Preview, retaining failed-save Retry.
- Copy task details from task menus and organize multiple selected Focus tasks, including moving them to Inbox.
- Preserve Reference contexts, normalize Reference saves, and consume existing closing brackets when inserting `[[` links.
- Stabilize mobile checklist handle dragging, note editing, draft saves, and iOS swipe dismissal with unsaved edits.

## Focus, review, reminders, and Pomodoro

- Credit active partial Pomodoro work once across pause, task switches, completion, retry, and restart; accumulate sub-minute remainders without counting an unfinished Pomodoro as complete.
- Add optional device-local Start and Due reminder times for date-only tasks, both off by default, without changing task dates or replaying past alerts.
- Offer Start only and Due only reminder policies; a selected advance time replaces the chosen date-time alert.
- Add a direct Android reminder-channel sound and vibration settings link.
- Show relative schedule dates in Focus and restore Review Due before Next Actions.
- Defer Waiting For follow-ups until their review date, falling back to their start date.
- Compact the mobile Review scope selector and Archive retention settings; clarify desktop Review actions and remove the arbitrary Next Actions count warning.
- Improve E-Ink accents, selected controls, and status visibility; complete Korean Manage settings translations.

## Projects, calendars, and desktop

- Link a read-only calendar event to a project, retaining its source and occurrence details with guarded recovery and sync.
- Handle excluded and moved subscribed-calendar occurrences and keep subscribed events visible while system calendars load.
- Use the shared date field for project Review dates, task typography for project rows, and compact empty project task lists.
- Clarify Area scope with a direct reset, compact Sort and Group controls, and keep the projects panel toggle beside the title.
- Group Data and calendar settings into expandable cards while keeping Settings search able to reveal their controls.
- Stabilize Timeline drag feedback and release editor ownership and autocomplete timers when their rows or windows disappear.
- Use a monochrome macOS menu bar icon.

## Sync, storage, and security

- Preserve edits made as sync finishes, keep them pending for the next upload, and report the result of the follow-up cycle that carries them.
- Retry deferred uploads automatically; let pull-to-refresh join a follow-up cycle without leaving the badge stuck syncing.
- Keep opted-out Appearance, Language, and GTD stamps off sync uploads and resolve equal-stamp settings consistently across devices and the Self-hosted server.
- Keep Dropbox disconnected when an in-flight refresh ends, and revoke access even when the saved access token has expired.
- Bind encrypted artifacts to their role and identity, with an explicit verified format upgrade and retained recovery archives.
- Preview supported browser attachments safely, download active or unknown formats, and refuse executable browser link protocols.
- Open supported local documents normally, reveal executable or unknown files in their folder, and refuse network/device attachment paths.
- Hold private mobile screens until canonical App Lock settings are available; avoid flashing the unlock panel within the configured relock delay.
- Keep speech Smart Parse and retries on the configured speech server; let local Whisper Auto detect the spoken language.
- Ignore read-side filesystem notifications and reduce unnecessary SQLite row copies and repeated Pomodoro receipt validation.
- Update node-forge, Hono, quinn-udp, rustix, OpenSSL, SQLite, and Rust HTTP dependencies for security and maintenance fixes.

## Widgets, Apple Watch, and integrations

- Keep Android widget rows stationary through overlapping Undo windows, then remove checked rows together.
- Open editable saved widget filters, include Reference where selected, and align saved Focus and Contexts routing and sorting.
- Use medium iOS widget space for more readable task rows and retain truthful reminder-capture dispositions.
- Expand desktop Local API and MCP with guarded ordinary-task reopening, duplicate-safe area creation/restoration, sections and people lists, task-list versions, conditional polling, and protected lifecycle actions.
- Add stale-write protection, durable retry-safe creates, and no-op PATCH handling to the Bun Local API helper.
- Publish independently versioned, non-root MCP container images for Cloud/API use, tested on native amd64 and arm64 runners.

## Native mobile preparation and release engineering

- Continue native Android and iOS parity work for capture, task and project menus, checklist gestures, bulk organization, reviews, widgets, shortcuts, background sync, calendar push, voice capture, and Sandbox isolation.
- Preserve native upgrade identities, credentials, App Groups, CloudKit routing, share extensions, Watch packaging, privacy manifests, and durable capture/command receipts.
- Reset a native iOS checklist without discarding unsaved task edits.
- Improve native startup, paging, tab retention, accessibility ownership, SQLite serialization, and source-built QuickJS/Whisper integration.
- These native clients remain on the upcoming 1.4.0 RC path; stable 1.3.9 still ships React Native mobile. Android 1.3.9 is the final RN release shared across production, open testing, and internal testing. After 1.3.9, testing channels carry native builds starting at 1.4.0.
- Extend device and simulator regression coverage, release diagnostics, dependency auditing, runner storage/apt recovery, and packaging validation.
- Preserve staged store rollouts and add release-confirmation automation. Refresh public docs for capture, reminders, project calendar references, automation, and encrypted-sync recovery.

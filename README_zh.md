# Mindwtr

中文 | [English](./README.md)

**把脑子里的事都倒出来。**

Mindwtr™ 是一款免费开源的待办应用，基于「搞定」（Getting Things Done，GTD）方法。记下任务和想法，拆成具体的下一步，再决定今天做什么。

**可离线使用 · 无需账号 · 无需订阅**

20,000+ 用户 · Windows、macOS、Linux、iPhone、iPad 和 Android

[**下载 Mindwtr**](https://mindwtr.app/#download) · [功能亮点](#功能亮点) · [快速开始](https://docs.mindwtr.app/start/getting-started) · [文档](https://docs.mindwtr.app/)

*Mindwtr 取自 "mind like water"（心静如水）：记下惦记的事，安心做眼前的事。中文社区也可以简称为「如水」。*

## 怎么用

把「筹备妈妈的生日」或「有空学吉他」记下来，再决定怎么处理。Mindwtr 会引导你走完这个过程，不需要先学会 GTD。

1. **先记下来。** 用桌面快捷键、手机小组件或系统分享，把任务和想法放进收件箱。
2. **想清下一步。** 把大计划拆成具体行动，用「等待中」跟进别人答应的事，把暂时不做的想法放进「将来/也许」。
3. **选一件去做。** 打开「聚焦」，查看今天的日程和下一步行动，按所处的地点或手边的工具筛选。
4. **每周回顾。** 跟着回顾向导检查项目、跟进等待事项，整理遗漏的任务。

## 功能亮点

- **完整的 GTD 流程。** 从收件箱整理、项目规划到每周回顾，全程有引导，让你既能安排眼前的行动，也能定期检查长期计划。
- **数据由你掌握。** 任务保存在设备上，断网也能用，还可以导出备份。同步是可选的，存哪儿由你选择：[iCloud、Dropbox、共享文件夹、WebDAV 或自己的服务器](https://docs.mindwtr.app/data-sync/)。
- **电脑和手机都能用。** Windows、macOS、Linux、iPhone、iPad 和 Android 都支持完整的 GTD 流程，并提供 20 种语言选项。
- **带着现有任务搬过来。** 从 Todoist、TickTick、OmniFocus 等应用[导入任务](https://docs.mindwtr.app/import/)，省去重新录入。
- **按需要添加工具。** 用日历安排时间，用重复任务处理日常事务，用备注和附件保存相关资料。AI 助手默认关闭，需要时再开启。

Mindwtr 专注于个人任务管理。你可以从简单的清单开始，按需要使用更多选项；没有连续打卡，也没有效率评分。

## 安装

完整且最新的安装指南请见[桌面端安装](https://docs.mindwtr.app/start/desktop-installation)与[移动端安装](https://docs.mindwtr.app/start/mobile-installation)。

快速选择：

- Windows：Microsoft Store、Winget、Chocolatey、Scoop 或 GitHub Releases。
- macOS：Mac App Store、Homebrew、TestFlight 测试版或 GitHub Releases。
- Linux：Flathub、Snap、AUR、APT/RPM 仓库或 GitHub Releases。
- Android：Google Play、F-Droid、IzzyOnDroid 或 GitHub Releases APK。
- iOS：App Store 或 TestFlight 测试版。
- Web / 自托管：[云端部署](https://docs.mindwtr.app/data-sync/cloud-deployment)或 [Docker 指南](docker/README.md)。

中国大陆 Android 用户：由于厂商应用商店的主体认证、备案及资质审核等流程需要额外预算和维护精力，Mindwtr 暂未上架小米、OPPO、vivo 等国内应用商店。你仍可在支持的 Android 设备上下载并安装[官方 APK](https://github.com/dongdongbh/Mindwtr/releases)。详情见[中文安装指南](https://docs.mindwtr.app/zh-Hans/start/mobile-installation#android)；也欢迎[捐赠支持项目](https://mindwtr.app/zh-Hans/donate)，帮助我们在需求和资源允许时评估这些渠道。

Windows 版本：代码签名由 [SignPath.io](https://signpath.io/) 免费提供，证书由 [SignPath Foundation](https://signpath.org/) 颁发 —— 申请已通过，证书待签发。详见[代码签名政策](https://mindwtr.app/signing)。
